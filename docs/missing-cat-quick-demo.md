# Missing cats: an easy two-minute demo

Stay signed in as admin. Use the prepared fictional **Tux** case.

**Missing-cat cases** keeps the ongoing case, its saved plan, and field feedback. **Lost cat navigator** gives a quick search suggestion from details you enter. The navigator's quick query does not replace or update the saved case.

## 1. Show the ongoing case

1. Open **Missing-cat cases** in Cats & map.
2. Scroll below the new-case form and select **Tux** in the case list.
3. Point to the reference photo, description, broad last-seen area/time, and active status.
4. Show its existing saved search plan and **Field evidence history**. You can use the saved plan immediately; a new agent request is unnecessary for this first part.

Say: “This is our shared case file. Anyone on the team can see what was reported and what has already been checked.”

If no saved plan exists, an active case offers **Generate and save search plan**. A case with a plan offers **Update search plan with feedback**. A pending case first needs your own reason, acknowledgement, and **Confirm missing case**.

## 2. Show how new evidence changes a plan

1. In **Human review reason / fictional field observation**, enter:

   `DEMO: This suggested area has standing floodwater. Do not send volunteers into it.`

2. Set **Observed at** to a valid time in the past.
3. Under **Related search zone**, choose one specific suggested zone. Do not leave General observation if you want to demonstrate excluding that zone.
4. Click **Log unsafe**.
5. Show the new feedback entry and the excluded zone. The saved plan becomes stale, so task preparation waits for an updated plan.
6. Click **Update search plan with feedback**. Wait for the result; show the remaining suggestions and their mode.

Say: “A volunteer's observation changes the plan. This area is removed because it was reported unsafe, and a coordinator reviews what happens next.”

Each unsafe example changes the saved fictional case. For repeat rehearsals, show the existing unsafe entry instead of excluding every remaining zone. Keep Tux active for the demo.

## 3. Show the quick navigator

1. Open **Lost cat navigator**, or click **Open navigator** on Tux's saved plan.
2. Check these fields yourself; the quick form does not automatically copy all details from the case:

| Field | Demo value |
| --- | --- |
| Name or nickname | Tux |
| Last-seen demo area | Miami Beach, matching the prepared case |
| Last seen, local date and time | Yesterday at 6:00 PM, or the actual past time shown on Tux's case |
| Coat, markings and behavior | Black tuxedo cat with white chest, white paws, and a small white spot below the nose. |

3. Click **Find likely search areas**.
4. Show **Record comparison**: the stored cat candidate, text-match score, and mode. Then show **Areas to verify** and select a circle or suggested-area button.
5. Point to the area's explanation, illustrative radius, and the new map legend.
6. Click **Prepare field-search task** to open a task draft. Review the access/safety fields, choose an assignee, and submit only if you want to create that fictional task.

Say: “I enter the last-seen details. The agent compares our stored records and suggests places to check. These are planning priorities, not a confirmed location.”

For feedback-aware follow-up on Tux, return to the saved plan in **Missing-cat cases**. The standalone navigator query is separate and does not automatically inherit that case's excluded zones.

## The easiest recording order

Tux case → existing feedback and saved plan → quick navigator → suggested area → task draft.

If time is short, show the existing unsafe feedback rather than adding another one. That demonstrates the full story without waiting for a fresh plan or consuming the remaining safe suggestions.
